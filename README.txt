全球新闻推送与语音朗读平台
===============================

项目概述：
---------
这是一个多功能新闻聚合和文字语音处理网站，具有以下核心功能：

主要功能：
---------
1. 新闻推送系统
   - 支持24个主要城市和地区的新闻展示
   - 实时获取聚合数据新闻API内容
   - 按类别筛选（社会、国内、国际、体育、娱乐、科技）
   - 关键词搜索功能
   - 自动更新和手动刷新

2. 语音朗读功能
   - 使用Web Speech API实现文字转语音
   - 支持多语音选择和参数调节
   - 可调节语速、音调、音量
   - 支持暂停、继续、停止操作
   - 新闻自动朗读功能

3. 文本编辑器
   - 富文本编辑区域
   - 实时语音朗读编辑内容
   - 文本操作（复制、分享）

4. 音频转换
   - 可将文本转换为语音播放
   - 支持MP3/WAV格式选择
   - 提供录音指导

5. 个性化设置
   - 城市选择和管理
   - 主题切换（浅色/深色/自动）
   - 自动朗读开关
   - 通知设置

技术特点：
---------
- 纯前端实现，无需服务器
- 响应式设计，支持移动端
- 现代化UI界面
- 本地存储用户偏好
- 聚合数据API集成

使用说明：
---------
1. 直接在浏览器中打开index.html即可使用
2. 首次使用建议允许浏览器麦克风权限（如需要）
3. 在设置页面确认API配置信息
4. 选择感兴趣的城市和新闻类别
5. 点击新闻项的"朗读"按钮可听新闻内容
6. 在文本编辑器页面可编辑文字并朗读
